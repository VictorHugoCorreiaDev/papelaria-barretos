Sistema web para gerenciamento de vendas, estoque e relatórios de uma papelaria.

---

## 🚀 Funcionalidades

- 🔐 Autenticação de usuário (Login)
- 📦 Cadastro de produtos
- ✏️ Edição e exclusão de produtos
- 📊 Controle de estoque
- 🛒 Registro de vendas
- 📄 Listagem de vendas
- 📈 Relatórios
- ⚡ Venda rápida com AJAX

---

## 🛠️ Tecnologias Utilizadas

- PHP 8+
- MySQL
- HTML5
- CSS3
- JavaScript
- AJAX

---

## 💻 Como Executar Localmente

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/HavocC-marcha/papelaria-barretos.git

Acesse a pasta
cd papelaria-barretos

Inicie o servidor PHP
php -S localhost:8000

Acesse no navegador
http://localhost:8000
```

🗄️ Configuração do Banco de Dados

Crie um banco no MySQL

Configure o arquivo:  Conexao.php


🌍 Deploy
